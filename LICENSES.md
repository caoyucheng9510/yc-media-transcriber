# Dependency And License Notes

This repository is implemented from scratch for V1.

- No code, templates, prompts, or test data were copied from `../VideoTranscriptAPI`.
- Runtime dependencies are installed from public packages declared in `pyproject.toml`.
- `ffmpeg` is installed in the Docker image from Debian packages.
- `yt-dlp`, FastAPI, Uvicorn, HTTPX, Pydantic, pytest, FunASR, ModelScope, and Torch keep their upstream licenses.
